#+title: dida.el — 滴答清单(Dida365) Open API 的 Elisp 客户端

=dida.el= 是滴答清单（Dida365，国际版 TickTick 同构）Open API 的 Emacs Lisp 底层库。
它只负责认证、HTTP 请求、错误/重试/限流，以及项目/任务资源的纯数据操作，*不碰 Org*。

Org 工作流（日常清单双向同步）在用户侧实现，见
[[file:DIDA-WORKFLOW.org][DIDA-WORKFLOW.org]] / [[file:dida-workflow.el][dida-workflow.el]]。

依赖 [[https://github.com/alphapapa/plz.el][plz]]（唯一外部依赖）。

* 安装

#+begin_src emacs-lisp
;; 从 GitHub 安装
(use-package dida
  :vc (:url "git@github.com:TomoeMami/dida" :rev :newest))
#+end_src

或从自建 ELPA：
#+begin_src elisp
(add-to-list 'package-archives
             '("TomoELPA" . "https://tomoemami.github.io/tomoelpa/snapshots/"))
(list-packages)
(package-install 'dida)
#+end_src

* 认证

** Personal API token（推荐，适合无人值守）

在滴答网页版「设置 → 账户 → API Token」生成 token，然后任选一种：

#+begin_src elisp
(setq dida-access-token "YOUR TOKEN")
;; 或写进文件（默认 ~/.emacs.d/didatoken）
(setq dida-token-file "~/.emacs.d/didatoken")
#+end_src

** OAuth

#+begin_src elisp
(setq dida-client-id "YOUR CLIENT ID")
(setq dida-client-secret "YOUR SECRET")
(setq dida-redirect-uri "http://localhost:1145")
(setq dida-oauth-port 1145)
;; M-x dida-authorize
#+end_src

国际版 TickTick：

#+begin_src elisp
(setq dida-api-base "https://api.ticktick.com"
      dida-oauth-base "https://ticktick.com")
#+end_src

* API 一览

所有函数在成功后返回解析后的数据（alist / list）；失败抛 =dida-api-error=，
可用 =dida-api-error-kind= / =dida-api-error-status= 判断。=dida-auth--ensure=
在每次请求前自动调用，token 过期会尝试 refresh。

2.4 起每个资源函数都有异步版本（如 =dida-api-get-task-async=），回调风格
=(CALLBACK &rest ARGS)=，回调只调用一次：成功 =(DATA nil)=，失败 =(nil ERROR-DATA)=；
=ERROR-DATA= 与 =dida-api-error-data= 形状一致。异步路径用 =run-at-time= 退避
重试，不阻塞 Emacs。同步版本保留，行为不变。

** 项目

| 函数 | 说明 |
|------+------|
| =dida-api-list-projects (&key offset limit)= | 列出全部项目（自动翻页） |
| =dida-api-get-project (pid)= | 项目信息 |
| =dida-api-get-project-data (pid)= | 项目 + 未完成任务（=tasks= / =columns=） |
| =dida-api-create-project (name &key color sort-order viewmode kind)= | 新建项目 |
| =dida-api-update-project (pid &key name color sort-order viewmode kind)= | 更新项目 |
| =dida-api-delete-project (pid)= | 删除项目（404 视为成功） |

** 任务

| 函数 | 说明 |
|------+------|
| =dida-api-get-task (pid tid)= | 单任务；不存在返回 nil |
| =dida-api-create-task (payload)= | 新建任务，返回创建后的 task alist |
| =dida-api-update-task (tid payload)= | 整体替换更新；payload 要完整 |
| =dida-api-complete-task (pid tid)= | 完成；404 返回 nil |
| =dida-api-delete-task (pid tid)= | 删除；404 视为成功 |
| =dida-api-move-task (tid from-pid to-pid)= | 移动到另一个项目 |
| =dida-api-complete-tasks (pid tids)= | 批量完成 |
| =dida-api-batch-tasks (&key add update)= | 批量新建/更新（≤50，含 add 时不会自动重试） |

** 查询

| 函数 | 说明 |
|------+------|
| =dida-api-list-completed (&key project-ids start end)= | 已完成任务（单次 ≤200） |
| =dida-api-list-completed-all (&key project-ids start end window-days)= | 按天切片拉完成历史并去重 |
| =dida-api-filter-tasks (&key project-ids start end priority tag kind status)= | 过滤任务 |
| =dida-api-undone-tasks (&key project-ids task-ids start end)= | 未完成任务（窗口 ≤14 天） |
| =dida-api-search-tasks (keywords &key project-ids tags status due-from due-to)= | 关键词搜索 |
| =dida-api-get-preference ()= | 用户偏好（主要是 timeZone） |

* 构造 payload

写接口是*整体替换*语义：只发自己管的字段会把远端未映射字段清空。
推荐流程：先 =dida-api-get-task= 取远端对象，再用
=dida-api-payload-from-remote= 建立在远端当前状态上的完整 payload，覆盖自己的字段后提交；
未映射字段（=tags/items/reminders/desc/startDate/sortOrder=）会被原样带回。

#+begin_src elisp
(let* ((remote (dida-api-get-task pid tid))
       (payload (dida-api-payload-from-remote remote)))
  (setq payload (plist-put payload :title "新标题"))
  (setq payload (plist-put payload :content "备注"))
  (setq payload (plist-put payload :priority 3))
  (setq payload (plist-put payload :status 0))
  (dida-api-update-task tid payload))
#+end_src

新建时用 =dida-api-task-payload= 组装，再交给 =dida-api-create-task=：

#+begin_src elisp
(dida-api-create-task
 (dida-api-task-payload
  :title "写周报"
  :project-id pid
  :content "备注"
  :priority 3
  :due-date "2026-11-06T18:00:00+0800"
  :is-all-day :json-false))
#+end_src

* 错误、重试与限流

- 错误统一为 =dida-api-error=，带 =:kind=（=auth/not-found/rate-limit/server/client/network/parse=）、
  =:status=、=:message=。
- 401 自动 refresh 并重试一次；429/5xx/网络错误按指数退避重试（幂等请求才重试）；
  =create= 不自动重试，避免重复建任务。同步路径用 =sleep-for= 退避，
  异步路径（=dida-api-*-async=）用 =run-at-time=，不会卡住 Emacs。
- =dida-api-max-retries=、=dida-api-backoff-base=、=dida-api-timeout=、
  =dida-api-connect-timeout= 可调。
- 写后回读校验由调用方决定；=dida-api-complete-task= 在 dida365 上偶发 200 但状态未变，
  自定义层可回读并用 =:status 2= 兜底。

* 时区

=dida-time-zone-offset=（默认 ="+0800"=）用于写 =dueDate=。
=isAllDay= 为 true 时只写日期；定时任务截到分钟。

* 自带 Org 工作流（可选）

2.0 的旧同步引擎与兼容函数已从库里删除；仓库只保留纯 API 层。
仓库根目录另有一个可选的用户侧工作流层 =dida-workflow.el=，
TomoELPA 构建 dida 包时默认的 `*.el` 规则会把它一起打包，所以装完 dida 后
它已经在 load-path 上：

#+begin_src elisp
(require 'dida)
(require 'dida-workflow)
(my-dida-auto-sync-mode 1)
#+end_src

用 use-package 时注意它不是独立包：

#+begin_src elisp
(use-package dida-workflow
  :ensure nil
  :after dida
  :config (my-dida-auto-sync-mode 1))
#+end_src

配置、命令、行为与限制见 [[file:DIDA-WORKFLOW.org][DIDA-WORKFLOW.org]]。
